Trigger Mechanisms:
1. Wheel Navigation (PageFlow.tsx:533-588):
   - Desktop only: if (!isDesktopRef.current) return; (PageFlow.tsx:556).
   - Delta threshold: Math.abs(e.deltaY) < 8 is ignored (PageFlow.tsx:564).
   - Direction: e.deltaY > 0 triggers next(); e.deltaY < 0 triggers prev() (PageFlow.tsx:569).
   - Internal scroll check: canScrollInDirection(target, pageEl, dir) (PageFlow.tsx:74-92) inspects ancestor tree for overflowY === 'auto' || 'scroll' and checks scrollTop bounds within EDGE_PX = 2px. If true, wheel passes through to scroll element.
   - Disabled scenes: ignored if currentPage?.id === 'demo' || currentPage?.gestures === false (PageFlow.tsx:559).
   - Transition Lock & Momentum Guard:
     - transRef.current locks navigation during transitions (PageFlow.tsx:543).
     - wheelActiveDuringLockRef tracks wheel events during lock.
     - 250ms quiet timer (wheelQuietTimerRef) prevents inertial trackpad events from queueing a second transition (PageFlow.tsx:535-538, 551).
   - Listener configuration: container.addEventListener('wheel', handleWheel, { passive: false }).

2. Touch Swipe Navigation (PageFlow.tsx:595-650):
   - Mobile only: if (isDesktopRef.current) return; (PageFlow.tsx:596, 623).
   - Single finger only: e.touches.length === 1 (PageFlow.tsx:597).
   - Edge zone rejection: startX < 24 || startX > window.innerWidth - 24 is rejected to avoid conflicting with browser history swipe (PageFlow.tsx:603-606).
   - Distance threshold: Math.abs(dx) < 56 (SWIPE_MIN = 56px) is ignored (PageFlow.tsx:634).
   - Axis ratio threshold: Math.abs(dx) <= Math.abs(dy) * 1.2 (SWIPE_RATIO = 1.2) is ignored; swipe must be predominantly horizontal (PageFlow.tsx:635).
   - Internal scroll check: canScrollXInDirection(touchTarget, pageEl, scrollDir) allows horizontal sub-scrollers (PageFlow.tsx:641).
   - Direction logic:
     - dx < 0 (swipe left): moves forward -> next().
     - dx > 0 (swipe right): moves backward -> prev().
   - Listener configuration: container.addEventListener('touchstart|touchend', ..., { passive: true }).

3. Keyboard Navigation (PageFlow.tsx:497-526):

PART 6. RESPONSIVE SYSTEM
--------------------------------------------------------------------------------

Breakpoints & Mechanisms:
1. Breakpoints:
   - md: (min-width: 768px): Primary architectural boundary. Separates horizontal phone gestures from vertical desktop wheel navigation.
   - sm: (min-width: 640px): Minor layout padding / typography adjustments.
   - lg: (min-width: 1024px): 4-column card grid in ContactSection.
2. Decision Mechanism:
   - Evaluated in PageFlow.tsx:300-321 via matchMedia('(min-width: 768px)').
   - Stored in React state isDesktop, defaulted to false (PageFlow.tsx:125).
   - Passed via PageStateContext to all scenes.
3. Server vs First Client Render (Flash / Hydration Mismatch): [RISK]
   - On server: typeof window === 'undefined' -> isDesktop is false.
   - On initial client mount: isDesktop initializes to false.
   - useIsomorphicLayoutEffect executes synchronously on client mount, evaluates matchMedia, and sets isDesktop = true on desktop screens.
   - Consequence: Desktop clients mount with mobile DOM structure, then immediately re-render desktop DOM. This is temporarily masked because LeadGate covers the screen on initial load, but if LeadGate is completed or disabled, it produces an audible layout flash.
